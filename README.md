# Proyecto de Despliegue Web - UVEG

## Descripción
Aplicación web optimizada y empaquetada para el Reto 2 de la Universidad Virtual del Estado de Guanajuato (UVEG).

## Estructura del Proyecto
- `/css/style.min.css`: Hoja de estilos minificada.
- `/js/main.min.js`: Código JavaScript minificado.
- `/img/`: Directorio de recursos de imagen.
- `index.html`: Estructura principal.

## Proceso de Empaquetado y Despliegue
1. **Optimización:** Minificación manual de CSS/JS y organización modular.
2. **Empaquetado:** Compresión en `.zip` para transferencia.
3. **Servidor:** Configuración de Server Block en Nginx escuchando en puerto 8080.
